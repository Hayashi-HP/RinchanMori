# ホームUI刷新レポート（v1.5.27）

## 変更境界

ホーム画面の見た目と情報設計だけを更新し、既存の認証、Google Apps Script API、同期、オフラインキュー、歩数、杜の成長、週間チャート、通信、ありがとう通知は維持した。

正式キャラクター素材 `assets/rinchan-face.svg` は変更していない。ヘッダーとヒーロー内で同じSVGを参照し、CSSによる配置と表示サイズだけを変更した。

## 依存関係

ホームは次の順で動作する。

1. `js/config.js` がGASエンドポイントを提供
2. `js/core/storage.js` がローカルキャッシュを提供
3. `js/core/api.js` / `js/core/sync.js` がGASと同期
4. `js/features/auth.js` がログイン状態を判定
5. `js/features/growth.js` / `chart.js` / `news.js` / `thanks-home-notice.js` が各カードを描画
6. `js/features/home-world.js` が挨拶とりんちゃんの一言を描画
7. `js/features/home-dashboard.js` が今日の歩数と目標進捗を描画
8. `js/v1138-home-boot.js` が同期後に全表示を再描画

## CSS整理

変更前のホームは16枚の静的CSSに加え、`config.js` から14枚、`device-class.js` から1枚が追加され、同じヘッダー、カード、ナビ、スクロール設定を複数の `!important` で上書きしていた。

変更後のホームは次の4枚だけを読み込む。

- `css/style.css`：既存画面と共有する基礎
- `css/ui-v042.css`：既存の可視状態・共通UI
- `css/v094-guide.css`：初回ガイド
- `css/home-design-system.css`：ホーム専用の最終ルール

ホーム以外のページでは従来の読み込みとモバイル補正を維持しており、今回の整理による影響範囲をホームに限定した。

## 表示確認

- 375 × 812：ログイン前、ログイン後、下部ナビ、縦スクロール、横はみ出しなし
- 1440 × 900：2カラムカード、最大幅、固定下部ナビ、横はみ出しなし
- ローカルのテストデータで今日6,842歩、目標8,000歩、残り1,158歩、週間19,182歩が正しく反映
- 下部ナビの各リンクは高さ67pxを確保
- ブラウザコンソールのエラー・警告なし（GAS通信を無効化したローカル表示テスト時）

## 残課題

- iPhone SafariとAndroid Chromeの実機でsafe area、文字レンダリング、慣性スクロールを最終確認する
- 本番GAS環境で同期前後、オフライン復帰、未読ありがとう通知を回帰確認する
- ホーム以外のページは旧CSS構成のままなので、今回のデザイントークンを段階的に横展開する
