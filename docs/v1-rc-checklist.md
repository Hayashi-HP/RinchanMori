# v1.0 RC 前チェックリスト

りんちゃんの杜を職員向けに展開する前の総合確認項目です。

## 1. 基本起動

- [ ] スマホでホーム画面が表示される
- [ ] りんちゃんの顔画像が切れずに表示される
- [ ] 下部メニューが画面下に自然に表示される
- [ ] ボタンを押したときに反応がある
- [ ] ボタン・リンクにマウスを合わせたとき指マークになる

## 2. 初回登録

- [ ] 社員番号を入力できる
- [ ] 氏名を入力できる
- [ ] 所属がスプレッドシート由来の部署一覧から選べる
- [ ] 誕生日4桁を入力できる
- [ ] 初回登録後にホームへ進める
- [ ] スプレッドシートに登録内容が保存される

## 3. ログイン・ログアウト

- [ ] 登録済み社員番号でログインできる
- [ ] 誕生日4桁が違う場合はログインできない
- [ ] ログアウトできる
- [ ] 同じ端末で再ログインしたとき、歩数履歴・ありがとう・プロフィールが復元される
- [ ] 別端末でログインしたとき、同じ本人データが復元される

## 4. ホーム

- [ ] 名前が正しく表示される
- [ ] 今日の一歩が表示される
- [ ] 今週の歩数グラフが表示される
- [ ] 1週間の歩数目標が設定済みの場合、残り歩数または達成表示が出る
- [ ] あなたの木が累計歩数・記録回数に応じて成長する
- [ ] 初回ガイドが未表示端末では表示される
- [ ] 初回ガイドを閉じると再表示されない

## 5. 歩数記録

- [ ] 活動日を選べる
- [ ] 歩数を入力できる
- [ ] 保存ボタンが保存中表示になる
- [ ] 保存後に完了表示が出る
- [ ] 最近の記録が表示される
- [ ] 歩数記録を修正できる
- [ ] 歩数記録を削除できる
- [ ] 保存後にホーム・マイページへ反映される

## 6. マイページ

- [ ] 表示順が指定どおりになっている
- [ ] プロフィールの所属がスプレッドシートの所属と一致する
- [ ] プロフィール編集がポップアップ形式で開く
- [ ] 健康宣言が鉛筆ボタンで編集できる
- [ ] 今週の目標が鉛筆ボタンで編集できる
- [ ] 1週間の歩数目標が鉛筆ボタンで編集できる
- [ ] ログアウトボタンの文字に左右余白がある
- [ ] ありがとうの受信・送信件数が表示される
- [ ] バッジが表示される
- [ ] 最近の活動が表示される

## 7. 通信

- [ ] 今日の杜が表示される
- [ ] ありがとうの広がりが1つのカードにまとまっている
- [ ] 上部に最新1件の代表表示が出る
- [ ] 下部に最近届いたありがとう一覧が出る
- [ ] 「グループホーム → 事務部」のような部署間表示が出る
- [ ] 「助けてもらった」など種類ラベルが表示される
- [ ] お知らせ・グループニュースが表示される

## 8. 杜

- [ ] 杜画面が表示される
- [ ] 部署・グループ単位の木が表示される
- [ ] 部署カードが重ならない
- [ ] 長い部署名が自然に改行される
- [ ] 個人または部署へのありがとう送信導線が機能する
- [ ] 更新ボタンで最新化される

## 9. 管理画面

- [ ] 登録者数が表示される
- [ ] 今日の記録者数が表示される
- [ ] 今日の歩数が表示される
- [ ] 部署別の動きが表示される
- [ ] 7日以上記録なしの候補が表示される
- [ ] 利用者一覧を検索できる

## 10. オフライン・同期

- [ ] オフライン時に歩数保存しても未送信として保持される
- [ ] オンライン復帰後に未送信データが再送される
- [ ] 保存後にサーバー最新状態が画面へ反映される
- [ ] 画面表示はキャッシュで素早く始まる
- [ ] 裏同期後に最新データへ更新される
- [ ] 通信失敗時に画面が固まらない

## 11. 速度・体感

- [ ] ホームがすぐ表示される
- [ ] 歩数記録画面がすぐ表示される
- [ ] マイページがすぐ表示される
- [ ] 通信ページが大きくもたつかない
- [ ] 杜ページの表示が許容範囲内
- [ ] 保存操作後の反応が分かりやすい

## 12. v1.0 RC 判定

次の条件を満たせば v1.0 RC とします。

- [ ] 登録・ログイン・ログアウトが安定している
- [ ] 歩数保存・修正・削除が安定している
- [ ] ありがとう送信・表示が安定している
- [ ] 同じ本人データが別端末でも復元される
- [ ] オフライン復帰でデータが失われない
- [ ] 主要画面に致命的な表示崩れがない
- [ ] 旧JS参照が残っていない
