# js/features

画面・機能別の JavaScript を置くディレクトリ。

## 予定ファイル

- `auth.js`：ログイン、初回登録、ログアウト、プロフィール保存
- `activity.js`：歩数保存、編集、削除、最近の記録
- `thanks.js`：ありがとう送信、受信、集計
- `news.js`：通信、お知らせ、既読
- `mori.js`：杜、部署、木、グループ表示
- `mypage.js`：マイページ、目標、健康宣言、バッジ
- `admin.js`：管理画面、集計、CSV

## 移行方針

既存の v番号付きファイルを一気に置き換えず、1画面ずつ差し替える。
