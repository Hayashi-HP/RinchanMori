# りんちゃんの杜

みんなで育てる、健康と笑顔の杜。

## 現在バージョン
**v1.5.11**

## 最終更新
2026-07-14

## 現在の位置づけ

Phase1 の基本機能はおおむね完成。
現在は Phase2「杜を生きた世界にする」と Phase3「チャレンジ・バッジ・イベント」を接続しながら拡張中です。

## v1.5.11 で修正された内容

- 七夕期間中は通常の花・ちょうちょ・小鳥の浮遊演出を非表示に固定
- 再描画時に通常装飾が一瞬だけカード前面へ出る問題を解消
- 竹を部署カードから離し、右下の背景側へ移動
- 夜空、星、天の川、竹だけの七夕背景へ統一
- 部署カード・人数・歩数・杜の見どころは変更せず維持
- 七夕CSSとイベントローダー、杜ページのキャッシュ番号を更新

## 現在の注意点

- 「今日はどこ？」は機能ファイルを残したまま画面表示のみ凍結中
- 年間イベントは12か月分のデータを持つ方式へ移行済み
- 月ごとの追加実装ではなく、共通カタログと共通エンジンで運用する方針
- Android ChromeおよびiPhone Safariは実機で最終表示確認が必要
- CSS / JS のHotFixファイルが増えているため、今後整理が必要
