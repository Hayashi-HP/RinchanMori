## 同期方針

正式データは Google スプレッドシートを正とします。
スマホ内のデータは即時表示用キャッシュとして使い、起動後に Apps Script と同期して最新状態へ更新します。

```text
アプリを開く
↓
手元キャッシュで即表示
↓
裏でサーバー同期
↓
最新データで画面更新
```
