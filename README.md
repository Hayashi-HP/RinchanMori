# りんちゃんの杜

みんなで育てる、健康と笑顔の杜。

## 現在バージョン
**v1.5.0**

## 最終更新
2026-07-13

## 現在の位置づけ

Phase1 の基本機能はおおむね完成。
現在は Phase2「杜を生きた世界にする」と Phase3「チャレンジ・バッジ・イベント」を接続しながら拡張中です。

## v1.5.0 で修正された内容

- Android Chromeでページ全体を縦スクロールできるよう、`html` / `body` / `.app` のスクロール責務を整理
- Androidだけ固定フッターを通常配置へ切り替える方式を廃止し、全端末で同じ固定フッター構造へ統一
- iPhoneのホーム・杜・通信・パスポートで、固定フッター下部が透けないよう背景レイヤーを追加
- パスポート画面のフッターも他画面と同じ固定位置・高さ・余白へ統一
- 共通モバイルレイアウトを `css/v150-mobile-foundation.css` として追加
- `device-class.js` から共通モバイルCSSを全主要ページへ読み込む方式に変更
- 七夕演出レイヤーを部署カードより前面へ移動し、短冊・星・竹がカード裏へ隠れないよう修正
- 七夕演出の再描画時にイベントクラスとイベントキーを維持
- 年間イベントカタログのイベントモジュールキャッシュ番号を `150` に更新

## 現在の注意点

- 「今日はどこ？」は機能ファイルを残したまま画面表示のみ凍結中
- 年間イベントは12か月分のデータを持つ方式へ移行済み
- 月ごとの追加実装ではなく、共通カタログと共通エンジンで運用する方針
- Android ChromeおよびiPhone Safariは実機で最終表示確認が必要
- CSS / JS のHotFixファイルが増えているため、今後整理が必要
