## v1.1.28 内容

- ホーム画面デザインをゲーム風にリニューアル
- 季節・時間帯メッセージを整理し、文章量を大幅削減
- ホーム「花が届いているよ」を追加
- 花受取カードをカード式へ全面リニューアル
- 「花を受け取る」を確認ボタンと統一デザインへ変更
- 花カードをコンパクト表示へ変更
- ありがとう受取動線を改善
- 通信ページのカードデザイン統一
- 杜ページの「りんちゃんの杜だより」を削除
- 杜ページを『今日の杜→杜の成長→杜マップ→杜の見どころ』構成へ整理
- 新規登録・ログイン画面のUI統一
- フッターナビのアクティブデザイン統一
- 最近の記録を1行カード化
- マイページ・歩数記録の文字サイズ調整
- PC・スマホ表示差異を多数修正
