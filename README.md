# りんちゃんの杜

みんなで育てる、健康と笑顔の杜。

## 現在バージョン
**v1.5.10**

## 最終更新
2026-07-14

## 現在の位置づけ

Phase1 の基本機能はおおむね完成。
現在は Phase2「杜を生きた世界にする」と Phase3「チャレンジ・バッジ・イベント」を接続しながら拡張中です。

## v1.5.10 で修正された内容

- 七夕イベントを背景演出だけに簡素化
- 短冊入力、願い表示、吹き出しUIを削除
- 夜空、星、うっすらした天の川、竹1本だけを表示
- 部署カード・歩数・通常の花はそのまま維持
- 七夕レイヤーを部署カードより背面に固定し、情報を隠さないよう変更
- 「杜の見どころ」を七夕メッセージへ統一
- 七夕関連CSS・JSと杜ページのキャッシュ番号を更新

## 現在の注意点

- 「今日はどこ？」は機能ファイルを残したまま画面表示のみ凍結中
- 年間イベントは12か月分のデータを持つ方式へ移行済み
- 月ごとの追加実装ではなく、共通カタログと共通エンジンで運用する方針
- Android ChromeおよびiPhone Safariは実機で最終表示確認が必要
- CSS / JS のHotFixファイルが増えているため、今後整理が必要
