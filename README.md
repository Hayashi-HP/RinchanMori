# りんちゃんの杜

みんなで育てる、健康と笑顔の杜。

## 現在バージョン
**v1.4.35**

## 最終更新
2026-07-12

## 現在の位置づけ

Phase1 の基本機能はおおむね完成。
現在は Phase2「杜を生きた世界にする」と Phase3「チャレンジ・バッジ・イベント」を接続しながら拡張中です。

## v1.4.35 で追加・修正された内容

- 「今日はどこ？」を凍結し、杜画面から非表示化
- `daily-rinchan-hunt.js` と `v134-daily-rinchan-hunt.css` は削除せず保留
- 12か月分のイベントを共通データで持つ `annual-event-catalog.js` を追加
- `event-calendar-engine.js` を年間イベントカタログ参照方式へ移行
- `event-loader.js` を年間イベントカタログ内の `module` 定義から動的読み込みできる形へ変更
- 杜画面で `annual-event-catalog.js` を先に読み込むよう接続
- 杜画面のキャッシュ番号を `175` に更新
