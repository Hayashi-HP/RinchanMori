# りんちゃんの杜

みんなで育てる、健康と笑顔の杜。

## 現在バージョン
**v1.4.34**

## 最終更新
2026-07-12

## 現在の位置づけ

Phase1 の基本機能はおおむね完成。
現在は Phase2「杜を生きた世界にする」と Phase3「チャレンジ・バッジ・イベント」を接続しながら拡張中です。

## v1.4.34 で追加された内容

- 杜画面に「りんちゃん、今日はどこ？」を追加
- 日付と利用者ごとに、りんちゃんの出現位置を毎日変更
- りんちゃんをタップすると、その日だけのメッセージと小さなプレゼントを表示
- プレゼントは1日1回だけ受け取り可能
- 受け取り履歴を端末内に最大100件保存
- 日本時間の日付で当日判定
- 杜画面のキャッシュ番号を `173` に更新
