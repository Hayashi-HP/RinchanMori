## v1.4.26 で修正された内容

- パスポート内の3つのチャレンジカードの左右余白修正方式を変更
- `passport-challenge-stack` を `display: contents` に変更し、外枠の幅指定を廃止
- 月間チャレンジ、部署チャレンジ、病院全体チャレンジの各カード自身に `margin: 0 16px 14px` を直接指定
- パスポート画面内のインラインCSSにも同じ指定を追加
- パスポート画面のキャッシュ番号を `165` に更新

## v1.4.25 で修正された内容

- iPhoneショートカットの歩数送信action `saveHealthSteps` をApps Script側で受け付けるように修正
- `saveHealthSteps` を `saveActivity` の互換actionとして処理
- ショートカット側をすぐ直せない場合でも、従来のショートカットから歩数登録できるようにした
- `writeLog` には元のaction `saveHealthSteps` を残し、互換処理であることが分かるようにした
- API応答には `normalizedAction: saveActivity` を返すようにした

## v1.4.24 で修正された内容

- Android Chromeで再びスクロールできない問題へ再対応
- 固定フッターが本文に重なる問題を修正
- `v128-mobile-polish.css` で `.app` の下余白を拡大
- `.app::after` を復活させ、固定フッター下の安全なスクロール余白を確保
- `.nav` の高さ、背景、重なり順を再調整
- パスポート画面内のインラインCSSにも、チャレンジカードの左右余白と下余白を明示
- ホーム、杜、歩数記録、通信、パスポート画面のキャッシュ番号を `164` に更新
